# Tietutka

Tietutka kertoo etukäteen, paljonko katutyöt hidastavat liikennettä ja milloin työn voi tehdä pienimmällä haitalla.

- Verkko-osoite: tietutka.fi
- Tuote pohjautuu Pontus Kettusen kehittämään Työmaatutka-prototyyppiin (pontuskettunen-cyber/tyomaatutka, jäädytetty haara `hsl-hakemus-2026-11`).
- Tietutka ei ole HSL:n eikä minkään kaupungin palvelu. Datalähteet mainitaan lisenssiensä mukaisesti.
